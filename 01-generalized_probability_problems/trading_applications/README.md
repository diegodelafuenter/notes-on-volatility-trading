# Trading Applications of Generalized Probability Problems

Companion document to the main volume `generalized_probability_problems.pdf`
in the parent folder. This 26-page reference compacts the trading
applications of all sixteen chapters into a single navigable document.

📄 **[Read the compiled PDF](trading_applications.pdf)**

## Structure

Each section mirrors a chapter of the main volume with three components:
- **The result** — a compact statement of the probabilistic result.
- **Trading applications** — the main content, with numerical claims
  quoted where relevant.
- **Reference** — a pointer to the corresponding chapter of the main
  volume for proofs and generalisations.

No proofs appear in this document; everything is justified in the
main volume. The relationship is deliberate: this document is the
navigable practitioner reference, the main volume is the
line-by-line defensible treatment.
